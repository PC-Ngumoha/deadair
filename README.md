# deadair

A project by P.C Ngumoha.

## Description

deadair is an AI-powered audio editing software designed to help podcasters automatically eliminate awkward silences and filler words from their recordings before publishing. It leverages machine learning to detect and remove unwanted audio segments, streamlining the post-production workflow.

## Features

- Automatic detection and removal of awkward silences
- Filler word elimination (um, uh, like, etc.)
- AI-powered audio analysis
- Batch processing capabilities
- Easy-to-use interface for podcasters
- High-quality audio output preservation

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/PC-Ngumoha/deadair.git
   cd deadair
   ```
2. Install dependencies and follow setup instructions in the documentation
   ```bash
   npm install
   ```
3. Start the web app
   ```bash
   npm run dev
   ```
